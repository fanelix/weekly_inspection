Hubungkan penyimpanan Drive

Frontend dan backend berjalan di Vercel. Pemilik perlu mengisi konfigurasi server agar laporan dan foto dapat disimpan. Teknisi tidak memberikan email atau akses Google pribadi.

Konfigurasi wajib

Environment variableIsi
APP_SECRETSecret acak minimal 32 karakter.
ADMIN_PASSWORDPassword admin unik minimal 12 karakter.
GOOGLE_CLIENT_IDClient ID OAuth Google.
GOOGLE_CLIENT_SECRETClient secret OAuth Google.
GOOGLE_REFRESH_TOKENRefresh token akun pemilik folder.
APP_ORIGINOrigin URL produksi tanpa path.

Isi langsung di Vercel → Project → Settings → Environment Variables, kemudian Redeploy. Jangan kirim password atau token melalui chat.

Buka panduan lengkap

Folder tujuan

Weekly Inspection berisi subfolder Radar dan RTS. Sharing mengikuti izin Drive. Folder publik dengan izin Editor juga membuat laporan dan foto dapat diakses/diedit melalui Drive.

Periksa setelah tersambung

Kirim satu laporan TEST ONLY Radar dan satu RTS, periksa foto/CSV/JSON di Drive, unduh ZIP, login admin, dan cetak/PDF sebelum aplikasi dipakai tim.

## Temuan dan perbaikan

| Temuan | Hasil perbaikan |
| --- | --- |
| Foto Moxa lama ditolak karena kolomnya dihapus dari schema aktif | Foto laporan terdahulu dapat dibaca dan masuk ZIP/cetak, dengan pemeriksaan otorisasi, nama, parent folder, dan digest bila tersedia |
| Masalah pada item lama hilang dari klasifikasi riwayat | Status riwayat membaca item historis pada laporan tersebut |
| CSV dan tampilan laporan menghilangkan jawaban item lama | Metadata arsip dipakai hanya untuk membaca laporan; ekspor gabungan menyatukan kolom lama/baru dan menjaga catatan multiline |
| Bagian Weather station berubah menjadi Weather sensor | Data historis ditampilkan di bagian Weather sensor |
| ID radar `LAINNYA` diterima tetapi tidak dapat dipakai | Label pilihan khusus ditolak sebagai ID baru sebelum penulisan Drive |
| Gagal memuat registry ditandai sudah selesai dan tidak bisa dicoba ulang | Pesan kegagalan dan tombol muat ulang tersedia |
| Respons registry lama menghapus radar yang baru saja ditambahkan | Daftar digabungkan agar respons yang terlambat tidak menghilangkan pilihan baru |
| Berpindah ke form lain saat tambah radar mengubah draf yang menerima hasil | Perpindahan dan penyuntingan dikunci selama penambahan radar |

Metadata arsip berada pada `legacyFields`; tidak ada item arsip yang dimasukkan kembali ke `fields` aktif atau diwajibkan pada inspeksi baru. Laporan/CSV di Drive tidak dimigrasikan atau ditulis ulang oleh audit.

## Verifikasi

- Validasi shared Apps Script/Vercel dan file generated sesuai dengan sumber.
- Tes transaksi mencakup retry konkuren, pengiriman terputus, foto yang berubah, kunci salah, dan akses file di luar parent laporan.
- Tes frontend mencakup draf, upload terpisah, ekspor, kegagalan cetak, radar baru, muat ulang registry, dan foto historis.
- Build Vercel dan bundle Apps Script berhasil; logo PNG pengguna tetap dipaketkan.

Jalankan `npm run check`, `npm test`, `npm run build`, dan `npm run bundle` untuk mengulang pemeriksaan. Tes menggunakan adapter Drive memori, bukan kredensial produksi.

## Batas pemeriksaan

Audit ini memverifikasi repository dan perilaku melalui tes otomatis. OAuth Google, environment variables aktual, deployment Vercel aktif, serta penyimpanan laporan dari perangkat teknisi memerlukan pemeriksaan produksi tersendiri. Runtime browser tidak tersedia pada lingkungan audit ini, sehingga pengujian tampilan browser langsung belum dilakukan.

Untuk domain produksi `https://weeklyinspection.vercel.app`, `APP_ORIGIN` harus sama persis dengan origin tersebut. Jika masih muncul “Asal permintaan tidak diizinkan”, periksa environment Production dan redeploy mengikuti `docs/vercel-deployment.md`; pengecekan origin tetap aktif.

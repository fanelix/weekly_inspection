# Vercel Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Frontend tema BSI dan backend Node.js di Vercel, dengan laporan/foto dalam Drive.

**Architecture:** Schema/validasi tetap bersumber dari appsscript. API serverless memakai Drive REST dan ID transaksi yang dialokasikan sebelum menulis. Frontend mengirim foto satu per satu, mempertahankan draf dan alokasi untuk retry.

**Tech Stack:** Node.js 24, built-in fetch/crypto, HTML/CSS/JavaScript; tanpa dependency runtime eksternal.

**Spec:** ../specs/2026-10-04-vercel-design.md

## Global Constraints

- Foto 1 MB; total 8 MB; request Vercel di bawah 4.5 MB.
- Root Drive dan subfolder Radar/RTS yang sudah dibuat dipertahankan.
- Tidak ada email teknisi, secret publik, ambang alat baru, atau dashboard data contoh.
- Theme dari referensi BSI; sentuhan minimum 48px; terang/gelap.
- Drive belum terhubung menghasilkan keterangan konfigurasi, bukan sukses palsu.

## Review Focus

- Respons hilang setelah begin/commit: retry memakai ID tetap.
- Dua upload/commit serentak: hanya satu file per ID.
- Manifest/file tampered: parent dan hash harus benar.
- Draf lama UUID: laporan tetap dapat ditemukan.
- Vercel env belum ada: schema tetap tampil, write gagal dengan keterangan tepat.
